# SeleniumJavaIndustryLevelFramework

An industry-level Selenium automation framework built with Java, TestNG, and Maven.
Features Page Object Model, Allure reporting, Log4j2 logging, thread-safe parallel
execution, and Jenkins CI/CD integration.

---

## 🚀 Tech Stack

| Tool | Purpose |
|---|---|
| Java 25 | Programming language |
| Selenium 4 | Browser automation |
| TestNG | Test runner |
| Maven | Build & dependency management |
| Allure | Test reporting |
| Log4j2 | Logging |
| Apache POI | Excel test data |
| Jenkins | CI/CD |
